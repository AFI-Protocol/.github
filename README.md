# .github

Organization-wide GitHub defaults for AFI Protocol.

## Contents

- [`profile/README.md`](profile/README.md) — the public organization profile
  shown at [github.com/AFI-Protocol](https://github.com/AFI-Protocol).

Community-health defaults (issue templates, contribution guides, security
policy) are added here if and when they are adopted organization-wide.
Per-repository documentation lives in each repository. The organization map
lives in [afi-protocol](https://github.com/AFI-Protocol/afi-protocol).
